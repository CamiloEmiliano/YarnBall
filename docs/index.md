# YarnBall Documentation Portal

Welcome to the engineering and quantitative finance documentation for **YarnBall**, a point-in-time Financial GraphRAG and supply-chain contagion analysis engine.

## Three Documentation Pillars

1. **Dual-Lens Technical Report (`docs/technical-report/`)**
   - Domain, mathematical, and software architecture monographs organized as a 5-chapter series ([ADR-00040](decisions/ADR-00040-ch0-system-atlas-and-docs-integrity-----.md)).
   - Start with [**Chapter 0: System Atlas & Architecture Overview**](technical-report/00-system-atlas.md).
2. **Static AST Python API Reference (`docs/reference/`)**
   - Griffe-extracted module, class, and function reference across all 13 runtime and pipeline packages (`mkdocstrings[python]`): [**API Reference Index**](reference/index.md).
3. **Architecture Decision Records (`docs/decisions/`)**
   - Immutable decision log (`ADR-00001` through `ADR-00044`): [**Master ADR Registry**](decisions/index.md).
